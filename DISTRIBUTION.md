# Distribution contents

The v1.0.6 release resumes launcher updates after the media cleanup. Earlier installers remain withdrawn and must not be re-uploaded.

No voice recordings, launcher music, game files or encryption keys are included. Voice modifications and experimental read-only amiibo support use files supplied locally by the user.

After v1.0.6, the Ocarina launcher graphics and Navi animation were restored from a local pre-cleanup backup at the user's explicit request on 2026-11-14. This is an unreleased launcher visual change; the published v1.0.6 installers remain unchanged. The restored graphics' original authorship and redistribution permission have not been established. Their hashes and restoration source are recorded separately in `tools/alpha/MEDIA-PROVENANCE.json`; a hash match is not a license or a rights verification. Other geometric project graphics are generated by `tools/alpha/make_project_art.py`, which preserves the recorded restored launcher files.

Hookshot copyright notices, GPL source and third-party licenses are retained. This does not relicense third-party materials or establish rights to distribute user-supplied files.

Both staging routes check distribution contents. The portable source build regenerates the game icon from reviewed source art rather than copying it from an older installation. Before packaging, run:

```text
python tools/alpha/distribution_guard.py <source-or-stage-directory>
```

Never publish local game data, translated game code, imported mods, private keys, debug packages or whole old media-bearing backups. The only exception for `fairy.bin` is the recorded, structurally valid launcher animation at its source or staged launcher path. The guard detects listed file types and unrecorded project media; it is not a complete binary audit or a legal guarantee. Inspect new assets and dependencies separately.

Old public branches and tags were rewritten to remove withdrawn media. Do not merge an old clone back into the cleaned history.
